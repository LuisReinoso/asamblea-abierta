Entre los ejes principales se establece un plazo máximo de un año para concretar un proceso de adopción, elimina la duplicidad de trámites entre las etapas judiciales y administrativas, fija plazos obligatorios para cada fase de procedimiento, dispone que un mismo juez conozca todo el proceso de adopción de una niña, niño o adolescente evitando cambios de juzgador, simplifica los mecanismos de citación y notificación, refuerza la aplicación del principio del interés superior del niño y la participación de niños, niñas, adolescentes conforme a su edad y grado de madurez.
